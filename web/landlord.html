Ways to play

Game night, any way you like

🛋️

Together on one device

Pass the tablet or gather round the TV. Up to 4 people (6 with Pro); fill empty seats with computer players. Games save themselves.

🌐

Online with a room code

Open a room and share the 6-letter code. Family joins from their own phones. The server rolls the dice and keeps the game moving if someone steps away.

🤖

Against the computer

Penny buys everything, Rex plays it steady and Ada trades like a shark. Pick your challenge.

Made for families

Easy for kids. Sneaky for grown-ups.

  • Big friendly buttons: Roll, Buy, Done. The game does the maths.
  • Short on cash? Houses sell and places mortgage automatically, so nobody gets stuck.
  • Quick games end after a set number of rounds: richest wins. Classic goes to the last one standing.
  • Lucky cards and Surprise boxes with silly, kid-friendly stories.
  • A cheerful soundtrack for every board that builds as the game heats up.
